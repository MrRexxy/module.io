Modul Magisk yang rapi dan mudah dicari

Cari modul untuk perangkat root kamu, lihat versi dan kebutuhan Android, lalu unduh langsung.

Modul untuk perangkat root Magisk.

Peringatan: selalu unduh aplikasi dari situs resminya (misalnya halaman rilis resmi di GitHub). APK dari sumber tidak dikenal bisa berisi malware atau sudah dimodifikasi. Aplikasi root punya akses penuh ke perangkatmu, jadi periksa dulu sumbernya sebelum memasang.

Cara memasang modul

  1. Unduh file modul (.zip) dari kartu di atas.
  2. Buka aplikasi Magisk, masuk ke tab Modul.
  3. Pilih "Pasang dari penyimpanan" lalu pilih file .zip tadi.
  4. Setelah selesai, mulai ulang perangkat.
